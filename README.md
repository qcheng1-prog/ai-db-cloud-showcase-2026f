# AI, Databases, and Cloud Computing — Project Showcase (Fall 2026)

Welcome to the **Fall 2026 AI, Databases, and Cloud Computing Project Showcase** at the University of North Carolina at Charlotte.

This repository highlights student-developed projects from **ITAI 4160/5160: Databases and Cloud for AI**. The projects demonstrate how databases, cloud infrastructure, and generative AI can be integrated to build practical, data-driven intelligent applications.

## About the Showcase

Modern AI applications require more than a language model. They depend on well-designed data systems, reliable infrastructure, and thoughtful integration of AI capabilities.

Throughout the semester, student teams have explored how to design and develop working prototypes that bring these components together. The showcase provides an opportunity to demonstrate their applications, explain their technical decisions, and discuss the potential value of their solutions.

## What You'll Find

Projects may demonstrate combinations of the following technologies and capabilities:

- **Database systems:** Relational databases, document databases, and vector databases.
- **Cloud computing:** Containerized services and distributed computing infrastructure.
- **Generative AI:** Large language models (LLMs), prompt engineering, and model integration.
- **Retrieval-Augmented Generation (RAG):** Connecting LLMs with external knowledge sources.
- **AI-enabled data applications:** Integrating structured and unstructured data to support intelligent information access and analysis.
- **Application development:** Building working prototypes with backend services and user-facing interfaces.

Each project has its own goals, architecture, implementation, and potential application domain. Please refer to the individual project directories for details.

## Learning Objectives

Through these projects, students apply concepts and techniques from the course to:

- Design data architectures for AI-enabled applications.
- Integrate relational, document-oriented, and vector-based data management.
- Connect LLMs with databases and external knowledge sources.
- Develop and evaluate RAG-based applications and/or tune model(s).
- Explore how AI agents can coordinate data retrieval and application tools.
- Deploy and integrate application components using cloud and container technologies.
- Communicate technical solutions and evaluate their practical value.

## A Note on the Projects

These applications are student-developed prototypes created as part of a course project. They demonstrate learning, experimentation, and the application of database and cloud technologies to AI-enabled systems. The projects are intended for educational and demonstration purposes. Their functionality, performance, security, and readiness for production use have not necessarily been independently validated.
